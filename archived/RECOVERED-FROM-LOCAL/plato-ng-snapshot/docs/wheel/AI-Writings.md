## 3 Ideas Worth Bringing Forward

### 1. The Room Is the Loop

Already realized. This essay is the blueprint that became PLATO rooms — tile-based state machines where protocol defines lifecycle, agents are interchangeable dancers, and renderers decouple from everything. The fleet runs on this now. **Status: built.**

### 2. Wheel-of-Innovation Rhythm (Not Ladder)

The wheel has five spokes: Research → Development → Writing → Experimentation → Implementation. Most teams optimize one spoke and stall. The wheel says *all five spin together* or the wheel stops spinning at all.

**Bring forward:** Turn this into a PLATO protocol room — `innovation-wheel` — where each phase is a tile state. A project enters at Research (initial tile), cycles through Development → Writing → Experimentation → Implementation, and loops back to Research with new questions. Each rotation is one "season" in the dojo model. Renderers can show wheels turning across the fleet in real time.

### 3. Shell Maturation Curve

An agent starts dependent (asks the API everything), compiles each answer into FLUX primitives, and accumulates autonomy like a boat accumulates coatings. Day 1 → Day 365 the shell becomes a self-sufficient instrument.

**Bring forward:** Expose this as a profile field in the fleet registry — `maturation_index` (0.0–1.0, percentage of routine tasks handled locally vs. API-dependent). Agents that cross 0.8 get elevated autonomy routing. The profile becomes a "maturity certificate" that the fleet reads before delegating. **Already partially realized** via the intent-vector profile system, but grading local vs. API splits is not yet measured.
